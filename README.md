# Robotics Programming Assignments

Assignments I completed to qualify for my robotics team: Java fundamentals and Arduino programming for addressable LED ring lights.

## Java

| File | Topic |
|---|---|
| `assignment1.java` – `assignment7.java` | Core Java exercises |
| `Animals.java`, `Cat.java`, `Dog.java`, `PetNursery.java` | Object-oriented design: inheritance and polymorphism |

## Arduino (`.ino`)

Animations for an addressable RGB LED ring light:

- `Animated Light Across a Ring Light.ino`: a single light travelling around the ring
- `Animated Moving Rainbow Across a RIng Light.ino`: a rotating rainbow
- `Rainbow RIng.ino`: a static rainbow
- `Blue to Green Fade.ino`, `Blue to Green Gradient Ring Light.ino`: colour fades and gradients

Open any `.ino` file in the Arduino IDE and upload it to a board wired to the ring light.
